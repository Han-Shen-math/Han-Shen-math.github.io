# Shen Han — Academic Website

Personal bilingual academic website for Shen Han (沈翰), focused on stochastic analysis, modern probability, and long-term explorations in brain-inspired efficient intelligence.

## Live site

The GitHub Pages deployment target is `https://han-shen-math.github.io/`.

## Long-form learning projects

- 300 Lectures on Probability & Stochastic Analysis
- 312 Lectures from Computer Architecture to Neuromorphic Intelligence & Compute-in-Memory

## Local development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run build
npm run build:github-pages
```

The `main` branch is deployed automatically through GitHub Actions.
